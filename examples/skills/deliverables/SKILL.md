# Deliverables

1. Save deliverables under `outputs/` with a stable name (e.g. `outputs/report.md`). To revise, edit the same file —
   git keeps every version, so do not create `report_v2.md` copies.
2. Add a one-line entry to `outputs/CHANGELOG.md` for each new or revised deliverable: date, file, what changed.
3. Prefer plain formats a person can open: Markdown, CSV, PNG, PDF, Python scripts.
4. Tell the user the file path; the chat shows download links for every changed file automatically.
